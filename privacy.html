Tab Orchard

Privacy policy

Effective 29 August 2026

Tab Orchard is a local-first Chrome extension for organising open tabs into trees and linking branches with Chrome tab groups. This policy explains what information the extension handles and how it remains under your control.

In short: Tab Orchard does not send your browsing information to its developer or to third parties. It has no account system, analytics, advertising or developer-operated server.

Information the extension handles

Open-tab information

To display and manage your tabs, Tab Orchard processes information Chrome provides about currently open tabs, including tab identifiers, titles, URLs, favicons, window membership, tab order, pinned state and Chrome tab-group membership.

Tree, group and Section information

Tab Orchard stores parent-child relationships, collapsed state, Chrome group metadata, user-created Section names, automatic group-assignment URL patterns and local settings inside the extension storage associated with your Chrome profile.

Notes and one-tab rules

If you create a note, Tab Orchard stores the note text, a cleaned or normalised matching address, the address used to reopen the page, and limited source details such as its title and favicon. One-tab rules similarly store their selected page, website or custom URL pattern. These records remain local until you delete them. Persistent notes are not created or displayed in private windows.

Recently Closed

If Recently Closed is enabled, Tab Orchard locally keeps up to 25 recently closed tab records, including the title, URL, favicon and former tree or Chrome-group context needed to reopen them. The default retention is seven days; Settings lets you disable the feature, select a retention period from one to 30 days, exclude domains and clear the stored records. If previews are enabled, a recently closed screenshot expires after 30 minutes.

Recovery information

To recover tree structure after a browser restart or extension reload, Tab Orchard retains a bounded local recovery journal for up to seven days. Recovery records use one-way URL fingerprints rather than readable page titles, URLs or group names. At most 20 window snapshots are retained.

Archived groups

If you choose to archive a tab group, Tab Orchard stores the titles, URLs, tab order and tree relationships needed to restore it. An archive remains in local extension storage until you restore or delete it.

Optional page previews

No screenshots are captured until you choose Enable previews and approve Chrome’s optional site-access request. Tab Orchard then keeps a bounded set of last-seen page screenshots in extension session storage for the current browser session. Preview images are not collected from private windows or synced, and are cleared when the browser session ends. Hiding the preview pane pauses new capture without removing Chrome’s permission; Clear preview cache removes existing images, and site access can be revoked in Chrome.

Optional fullscreen auto-hide

If you enable the experimental fullscreen feature, Tab Orchard requests access only to the websites you list, or to all websites if you explicitly choose that option. It dynamically attaches a small listener that observes only whether the page enters or leaves fullscreen. It does not inspect the video, page content, account or viewing history. If enabled, a temporary restore button may be shown after fullscreen only when Chrome confirms that Tab Orchard closed its side panel.

Diagnostics

Optional fullscreen and quick-picker diagnostics stay in local extension storage. They record feature state, Chrome API outcomes, timings, and tab or window identifiers needed to investigate behavior. They do not record URLs, page titles, note text, screenshots or page content, and can be cleared from Settings.

How information is used

Tab Orchard uses this information only to provide and improve its user-facing tab organisation, navigation, grouping, note, preview, archive, Recently Closed and recovery features. It does not use browsing information for advertising, profiling, credit decisions or any unrelated purpose.

Storage and transmission

  • Extension state is stored locally in the Chrome profile using Chrome’s extension storage APIs. Tab Orchard does not use Chrome Sync for this data.
  • Tab Orchard does not transmit extension data to the developer or to a developer-operated service.
  • Tab Orchard does not sell or share extension data with third parties.
  • Tab Orchard contains no analytics SDK, advertising SDK or remotely hosted executable code.

Permissions

  • Tabs: reads and manages currently open tabs so it can display, organise, activate, move and close them.
  • Tab groups: discovers and manages Chrome tab groups linked to tree branches.
  • Web navigation: identifies when a webpage creates a new tab and records the source-target relationship.
  • Scripting: dynamically attaches the fullscreen-state listener only to websites approved for the optional fullscreen experiment.
  • Storage: stores tree state, settings, notes, rules, archives, Recently Closed metadata, diagnostics and recovery information locally.
  • Side panel: displays the tab-tree interface in Chrome’s side panel.
  • Active tab: provides a temporary user-initiated grant used for supported previews.
  • Optional site access: requested only when you enable previews or approve websites for the fullscreen experiment.

Your choices and deletion

You can pause previews and clear their cache, disable or clear Recently Closed, delete notes and one-tab rules, remove automatic group patterns, clear diagnostics, restore or delete archived groups, and remove the extension at any time. Chrome also lets you review or revoke optional site access from the extension’s details page. Removing the extension removes its local extension storage from the Chrome profile.

Chrome Web Store Limited Use

Tab Orchard’s use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for Tab Orchard’s disclosed user-facing tab-management features, is not transferred for advertising or unrelated purposes, and is not made available to the developer or third parties for humans to read.

Changes to this policy

If Tab Orchard’s information practices change, this page will be updated before a release using those practices is published. Material changes will also be disclosed in the extension or its Chrome Web Store listing where required.
